# Estante Literária

## Sobre:
A **Estante Literária** é uma aplicação voltada para leitores que querem cadastrar suas leituras de forma interativa, obtendo uma contagem de páginas lidas ao mesmo tempo em que decoram seu próprio ambiente virtual de livros.

## Lista de funcionalidades:
- **Cadastro e login de usuários**
- **Busca de livros por API com fallback manual:** Permite que o usuário busque os livros com os dados completos (autor, editora, quantidade de páginas, entre outros) ou os cadastre manualmente caso necessário.
- **Avaliação dos livros:** Permite que o usuário classifique o livro com até cinco estrelas e registre sua opinião sobre a leitura, a escrita do autor ou o que achar relevante, bem como o registro manual de suas citações preferidas.
- **Personalização do livro:** Permite que o usuário escolha a cor e o tamanho (pequeno, médio, grande) que representarão a lombada do livro na estante.
- **Estante virtual interativa:** Exibe os livros cadastrados em prateleiras virtuais, refletindo visualmente as escolhas de cores e proporções.
- **Progressão por níveis:** Cálculo automático do total de páginas lidas para elevar o nível do usuário e liberar novas customizações na estante, como escolha de cor e desbloqueio de objetos decorativos para a estante.
- **Card de citações:** Cards exibidos assim que o usuário clica em um dos livros de sua estante. Os card vão exibir as citações favoritas do leitor, de forma aleatória a cada clique que ele der no livro.
